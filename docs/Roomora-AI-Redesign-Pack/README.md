# Roomora AI Redesign Pack

Bu paket FireVibe AI, Google Stitch, Claude Design, Uizard ve benzeri arayuz araclarinda kullanilabilir.

## Dosyalar

- `01-reference-home.png`: Tasarim sistemi referansi - Ana Sayfa
- `02-reference-bills.png`: Tasarim sistemi referansi - Faturalar
- `03-reference-quick-expense.png`: Tasarim sistemi referansi - Harcama Ekle
- `04-reference-settings.png`: Tasarim sistemi referansi - Ayarlar
- `05-current-bill-edit.png`: Yeniden tasarlanacak - Faturayi Duzenle
- `06-current-recurring-expense.png`: Yeniden tasarlanacak - Duzenli Gider Ekle
- `07-current-bill-detail.png`: Yeniden tasarlanacak - Fatura Detayi
- `08-current-expense-detail.png`: Yeniden tasarlanacak - Harcama Detayi
- `PROMPT.md`: Araca yapistirilacak tam prompt

## Kullanim

1. Sekiz PNG dosyasini araca yukleyin.
2. `PROMPT.md` icindeki Ingilizce promptu tek mesaj olarak gonderin.
3. Arac sorarsa `Mobile app`, `iOS and Android`, `Light theme` ve `4 screens` secin.
4. Gorsel siniri varsa once 01-04 referanslarini, ardindan o turda yenilenecek hedef ekranlari yukleyin.

01-04 numarali ekranlar yeniden tasarim hedefi degildir. Aracin bu ekranlari degistirmek yerine 05-08 ekranlarini ayni tasarim sistemine tasimasi gerekir.
